## 安装与使用

下载相应完整包并解压，将含 `SKILL.md` 的整个技能目录放入 Codex 的 `~/.codex/skills/`，然后重新启动或开启新会话。

史料版是九个独立 Skill；小说版是一个完整 Skill，内含九个人物模型及研究依据，名称为 `three-kingdoms-romance-thinking`。两个版本使用不同目录，可同时安装。

示例：

> 用史料版诸葛亮视角检查这个项目的战略前提、资源约束与责任分配。

> 用《三国演义》版诸葛亮视角分析同一个项目，给出判断方法、行动步骤和失败边界。明确区分小说情节与现实类比。

带上目标、事实、限制和可承担代价。模型是现代提炼，不能将小说情节当作史实，也不能把古人的成功当作现实结果的保证。

整理：Zero Wong。提炼方法来自[女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill)。各包保留研究来源与验证范围。
